# Netflix Data Analysis Using Python

This project focuses on analysing the Netflix dataset using Python. It includes data exploration, cleaning, analysis, and visualization to identify useful patterns and insights.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab

### Analysis Tasks
- Data Cleaning and Preparation
- Content Type Analysis
- Country-Wise Content Analysis
- Release Year Trend Analysis
- Content Rating and Genre Analysis
- Netflix Business Insights

### How to Run
1. Download the code file from this repository.
2. Open Google Colab.
3. Upload the code file or notebook.
4. Upload the required Netflix dataset.
5. Run the code to view the analysis and visualizations.
